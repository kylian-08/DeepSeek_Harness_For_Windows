# 我花了一周，把 DeepSeek 的 Agent 从命令行里拖出来了

先说结论：这玩意儿现在长这样，双击图标就开，跟打开一个普通软件没有区别。

![主界面](screenshots/01-main.png)

事情挺简单的。DeepSeek 官方那个 Agent（名字叫 Harness）我一直在用，能力没得挑，就是——它不给你一个"打开"的方式。你想用它，得先装 Node.js，然后在一个黑乎乎的窗口里敲一行命令，等它吐出一行网址，再手动开浏览器进去。每次启动都像把家里那台老台式机重新点一遍。

我自己能忍，但我身边有人忍不了。我试着把链接发给朋友，收到的回复基本是三种："这是啥""怎么用""算了"。

于是就有了这个项目：一个 Windows 桌面壳，双击图标，窗口自己弹出来，背后该装的东西我全打包进去了。对用的人来说它就是个软件；对我来说，它是把官方那个工具翻译成了正常人能理解的样子。

后来越做越上头，又往里塞了不少私货：

- 官方鲸鱼图标做了 5 套配色，设置里点一下立刻换，窗口和任务栏一起变
- 内置两个调好的模式，一个偏稳一个偏活，新建会话直接选，不用自己调
- 数据跟命令行版完全互通，两边换着用，聊天记录一条不丢
- 桌面版开着再开网页版也不打架，端口会自动让路

---

**Q：这不就是套了个浏览器的壳？**

A：壳是真的，但壳里打包的东西也是真的：Node 24 运行时、预编译好的原生模块、裁剪到最小的应用体积。下载下来双击就能用，电脑上什么都不用装。光"不用装 Node"这一条，就已经劝退过一大半人了。

**Q：和官方版到底差在哪？**

A：底层是同一个东西，数据也共用同一个目录。差别全在入口和体验：官方版要终端加浏览器，这个双击就行；另外加了图标切换、端口自适应、预装预设这些官方没有的小功能。

**Q：聊得多了会不会卡？**

A：会话按项目分开存，互不干扰；官方自带的压缩机制会控制对话长度，不会无限膨胀。

**Q：为什么没签名？**

A：个人项目，买证书的钱暂时没有，等哪天用的人多了再说。代码是 MIT 开源的，信不过可以自己构建比对。
